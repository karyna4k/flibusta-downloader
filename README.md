Мощный, быстрый и удобный CLI-инструмент для **полного многопоточного выкачивания книжных серий и циклов** напрямую с официальной библиотеки **Флибуста ([flibusta.is](http://flibusta.is))**.

## 🌟 Ключевые возможности

- ⚡️ **Многопоточная выкачка:** параллельная загрузка всех книг серии на максимальной скорости (с настраиваемым числом потоков `--threads`).
- 📖 **Поддержка всех форматов:**
  - **FB2** (автоматически распаковывает `.fb2.zip` в чистый `.fb2`, либо сохраняет исходный zip через `--keep-zip`).
  - **EPUB**
  - **MOBI**
  - **PDF**
- 🧠 **Умная дедупликация (Unique Mode):**
  - На Флибусте часто хранится по 3–6 разных переводов или сканов одной и той же книги.
  - Утилита автоматически выбирает наиболее качественный и полный перевод для каждого номера в серии (или скачивает все через `--all-editions`).
- 🔎 **Встроенный интерактивный поиск:** найдет серию по названию и предложит удобный выбор (`flibusta-dl --search "Ведьмак"`).
- 🏷 **Правильная нумерация и порядок:** файлы именуются по стандарту `01. Название книги - Автор.fb2`.
- 📁 **Авто-каталогизация и сводки:** сохраняет серию в отдельную папку с файлами `series_info.txt` и `series_info.json` (список книг, порядок, авторы, жанры, аннотации).
- 🔒 **Чистое прямое подключение:** работает напрямую с официальным сервером `http://flibusta.is` без левых рекламных редиректов. При необходимости поддерживает работу через Tor / SOCKS5 прокси (`--proxy socks5://...`).
- 🎨 **Красивый терминальный интерфейс (Rich):** таблицы серии, прогресс-бары в реальном времени, статистика скорости и объема.

## 📦 Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/Ivankolp/flibusta-downloader.git
cd flibusta-downloader
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Создание глобальной команды `flibusta-dl`
```bash
chmod +x flibusta_downloader.py
sudo ln -sf $(pwd)/flibusta_downloader.py /usr/local/bin/flibusta-dl
```

## 🛠 Примеры использования

### 1. Скачать серию по номеру ID или официальной ссылке (по умолчанию в FB2)
```bash
flibusta-dl 1824
# или по прямой ссылке:
flibusta-dl "http://flibusta.is/sequence/1824"
```

### 2. Найти серию по названию (интерактивный поиск)
```bash
flibusta-dl --search "Ведьмак"
# или просто передав поисковый запрос:
flibusta-dl "Метро 2033"
```

### 3. Скачать в формате EPUB или MOBI в 8 потоков
```bash
flibusta-dl 1824 --format epub --threads 8
```

### 4. Скачать только определенные книги серии
```bash
# Книги с 1 по 3 и книга 5:
flibusta-dl 1824 --books 1-3,5
```

### 5. Скачать абсолютно все редакции и переводы (без дедупликации)
```bash
flibusta-dl 1824 --all-editions
```

### 6. Указать папку для сохранения и пропустить подтверждение
```bash
flibusta-dl 2192 -o ~/MyBooks -y
```

### 7. Использование через Tor / SOCKS5 прокси
```bash
flibusta-dl 2192 --proxy "socks5://127.0.0.1:9050"
```

## ⚙️ Все параметры командной строки

| Параметр | Описание |
| :--- | :--- |
| `target` | ID серии (напр. `2192`), URL серии или текст для поиска |
| `-s, --search` | Поиск серии по названию на Флибусте |
| `-f, --format` | Формат книги: `fb2` (по умолч.), `epub`, `mobi`, `pdf` |
| `-t, --threads` | Количество параллельных потоков загрузки (по умолч.: `5`) |
| `-o, --output` | Папка для сохранения (по умолч.: `./downloads`) |
| `-u, --unique` | Оставлять один лучший перевод для каждого номера книги (включено по умолчанию) |
| `--all-editions` | Скачивать абсолютно все переводы и издания каждой книги |
| `-b, --books` | Фильтр по номерам книг (например: `1-5,7,10`) |
| `-m, --max-books` | Скачать не более N книг |
| `--keep-zip` | Сохранять FB2 в архивах `.zip` (не распаковывать) |
| `--force` | Принудительно перезаписывать уже скачанные файлы |
| `--host, --url` | Адрес сервера Флибусты (по умолч.: `http://flibusta.is`) |
| `--proxy` | HTTP или SOCKS5 прокси (например, для Tor) |
| `-y, --yes` | Не запрашивать интерактивное подтверждение перед загрузкой |
